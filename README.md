# Sarashina Translate for Firefox

[Sarashina Translate API](https://docs.sarashina.ai/api-reference/translate)（SB Intuitions）を使って、
ウェブページを **英語 ⇔ 日本語** に翻訳する Firefox 拡張機能です。
UI と翻訳の仕組みは [TWP - Translate Web Pages](https://github.com/FilipePS/Traduzir-paginas-web) を参考にしています。

## 機能

- **ページ翻訳**: ページの文章をその場で訳文に置き換えます。リンクや太字などのインライン要素は残したまま、語順の入れ替わりにも対応します。
- **原文に戻す**: ワンクリック（またはショートカット）で元の文章に戻せます。
- **原文ツールチップ**: 翻訳後の段落にマウスを重ねると原文を表示します（設定で無効化可）。
- **選択テキストの翻訳**: 右クリックメニューまたはショートカットで、選択範囲の翻訳結果を吹き出しで表示します。日英の向きは自動判定です。
- **ポップアップ内の翻訳ボックス**: 任意のテキストを入力して翻訳できます。
- **常に翻訳するサイト**: サイトごとに、開いたら自動で翻訳するよう設定できます（そのサイトへのアクセス権限だけを追加で要求します）。
- **動的なページへの追従**: 後から読み込まれた文章や、ページ側で書き換えられた文章も翻訳します。

| ショートカット | 動作                              |
| -------------- | --------------------------------- |
| `Alt+Shift+T`  | ページの翻訳 / 原文表示を切り替え |
| `Alt+Shift+Y`  | 選択テキストを翻訳                |
| `Alt+Shift+S`  | ポップアップを開く                |

（`about:addons` → 歯車メニュー →「拡張機能のショートカットキーの管理」で変更できます）

## API の制約への対応

Sarashina Translate API には次の制約があります。

- 1 リクエストにつき 1 テキスト、最大 5,000 文字（Unicode コードポイント）
- 対応言語は `ja` と `en` のみ
- レート制限は **6 リクエスト/分**（sarashina3-translate）

ページ全体を素直に段落ごとに翻訳すると数分かかってしまうため、この拡張機能は次のように動きます。

1. **まとめて送る** — 複数の段落を `[1] …` `[2] …` のような番号付きの行にまとめ、1 リクエスト（約 4,500 文字まで）で翻訳します。返ってきた訳文の番号が崩れていたら、そのまとまりを半分に割って送り直します。
2. **見えている部分から訳す** — 画面に表示されている（またはその近くの）段落だけを送り、スクロールに合わせて続きを翻訳します。
3. **レート制限を守る** — 直近 60 秒のリクエスト数を数え、上限に達したら枠が空くまで待ちます。待っている間に積まれた段落は次のリクエストにまとめて詰め込みます。`429` が返った場合は `Retry-After` に従います。
4. **キャッシュ** — 一度翻訳した文はブラウザ内に保存し、同じ文を二度と送りません。
5. **翻訳不要な文はスキップ** — 英→日翻訳では日本語だけの段落を、日→英翻訳では英語だけの段落を送りません。

インライン要素（リンクなど）は `<g1>here</g1>` のような目印を付けて送り、訳文中の目印の位置に合わせて既存のテキストノードの中身だけを書き換えます。DOM の構造（要素の追加・移動）は変えないので、React などで作られたページでも壊れにくくなっています。

翻訳中は画面右下に進捗（残り件数・次の API 枠までの秒数）が表示されます。

## インストール

### 開発版を一時的に読み込む

1. Firefox で `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」から `src/manifest.json` を選ぶ
3. 設定画面が開くので、[Sarashina API コンソール](https://chat.sarashina.ai/dashboard/api-keys) で発行した API キーを入力し、「接続テスト」で確認する

または `npm install && npm start` で、拡張機能を読み込んだ Firefox を `web-ext run` で起動できます。

### パッケージの作成

```sh
npm install
npm run build   # dist/ に .zip を出力
```

Firefox の通常版で恒久的にインストールするには、[addons.mozilla.org](https://addons.mozilla.org/developers/) で署名する必要があります。

## API キーの取り扱いについて

Sarashina のドキュメントでは、API キーをクライアントサイドのコードに埋め込まないよう推奨しています。
この拡張機能はキーを **コードには含めず**、利用者自身が入力したキーをそのブラウザの `storage.local` にだけ保存します。
キーは `https://api.sarashina.ai/v1/translate` へのリクエストの `Authorization` ヘッダー以外には使われません。
共有のパソコンでは使わない、使い終わったら設定画面から削除するなど、取り扱いにご注意ください。

翻訳のため、表示中のページの文章が Sarashina API に送信されます。

## 権限

| 権限                          | 用途                                                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| `activeTab`                   | ツールバーボタン・右クリックメニュー・ショートカットを使ったタブにだけスクリプトを注入する |
| `https://api.sarashina.ai/*`  | 翻訳 API の呼び出し                                                                        |
| `storage`, `unlimitedStorage` | 設定と翻訳キャッシュの保存                                                                 |
| `menus`                       | 右クリックメニュー                                                                         |
| `*://*/*`（任意）             | 「常に翻訳するサイト」を有効にしたサイトについてのみ、そのサイトへの権限を個別に要求する   |

## 開発

```
src/
  manifest.json
  background/         背景ページ（ES modules）
    background.js     メッセージ処理・タブへの注入・メニュー・ショートカット
    api.js            Sarashina Translate API クライアント
    scheduler.js      翻訳キュー（バッチ化・再送・キャンセル・重複排除）
    batch.js          複数段落の詰め込み／分解
    ratelimiter.js    スライディングウィンドウ方式のレート制限
    cache.js          翻訳キャッシュ
  content/content.js  ページ翻訳本体（必要なときだけ注入）
  common/lang.js      日英判定（背景ページ・コンテンツ・ポップアップ共通）
  popup/, options/    ポップアップと設定画面
test/                 ユニットテスト・結合テスト（node:test）
test/e2e/             コンテンツスクリプトの E2E テスト（Playwright + Chromium）
```

```sh
npm test            # ユニットテスト・背景ページの結合テスト
npm run test:e2e    # コンテンツスクリプトの E2E テスト（playwright が必要）
npm run lint        # web-ext lint + prettier
```
