Sarashina Translate の設定

API キー

Sarashina API コンソール で発行した API キーを入力してください。キーはこのブラウザ内（storage.local）にのみ保存され、 api.sarashina.ai への翻訳リクエスト以外には送信されません。

翻訳

Sarashina Translate API (sarashina3-translate) の既定のレート制限は 6 RPM です。 この拡張機能は複数の段落を 1 リクエスト（最大 5,000 文字）にまとめ、画面に表示された部分から順に翻訳します。 契約で上限が引き上げられている場合のみ変更してください。

常に翻訳するサイト

    まだありません。ポップアップの「このサイトを常に翻訳」から追加できます。

    キャッシュ

    一度翻訳した文はこのブラウザに保存され、再度 API を呼び出しません。
